      In this version the program is kept separately, not in these 26 memory locations. In a Von Neumann computer, the program and its data share the same memory.

      Instruction reference
      InstructionMeaningExample
      LDR Rd, <memory ref>Load the value in memory location <memory ref> into register d.LDR R1, 10
      STR Rd, <memory ref>Store the value in register d into memory location <memory ref>.STR R1, 10
      ADD Rd, Rn, <operand2>Add <operand2> to the value in register n and store the result in register d.ADD R1, R2, #5
      SUB Rd, Rn, <operand2>Subtract <operand2> from the value in register n and store the result in register d.SUB R1, R2, R3
      MOV Rd, <operand2>Copy <operand2> into register d.MOV R1, #0
      CMP Rn, <operand2>Compare the value in register n with <operand2>. The result is used by the next conditional branch.CMP R1, #10
      B <label>Always branch to the instruction at <label>.B loop
      B<condition> <label>Branch to <label> if the last comparison met the condition: EQ equal, NE not equal, GT greater than, LT less than.BEQ done
      AND Rd, Rn, <operand2>Bitwise AND of the value in register n and <operand2>, stored in register d.AND R1, R2, #1
      ORR Rd, Rn, <operand2>Bitwise OR of the value in register n and <operand2>, stored in register d.ORR R1, R2, #8
      EOR Rd, Rn, <operand2>Bitwise exclusive OR of the value in register n and <operand2>, stored in register d.EOR R1, R2, R3
      MVN Rd, <operand2>Bitwise NOT of <operand2> (every bit flipped), stored in register d.MVN R1, R2
      LSL Rd, Rn, <operand2>Logical shift left the value in register n by <operand2> places, stored in register d.LSL R1, R2, #2
      LSR Rd, Rn, <operand2>Logical shift right the value in register n by <operand2> places, stored in register d.LSR R1, R2, #1
      HALTStop the program.HALT

      Notes

      • <operand2> is either #n, a denary value such as #25, or Rm, the value in a register such as R6.
      • <memory ref> is a memory address written as a plain number, such as 10. Addresses go from 0 to 25.
      • The registers are R0 to R12.
      • A label is a name followed by a colon, such as loop:, at the start of a line. An instruction can follow it on the same line.
      • Anything after // on a line is a comment and is ignored.
      • Values are unsigned. If a result does not fit in the word size, it wraps round.
