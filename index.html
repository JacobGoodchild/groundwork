Penguin Forms

Plugin for JetBrains Rider · Free and open source

A Visual Studio-style Windows Forms designer for Rider on Linux. Drag controls from the toolbox, set their properties and events, and switch between design and code with F7. The code stays exactly as Visual Studio writes it, so a form designed on Linux opens unchanged in Visual Studio on Windows.
