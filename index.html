Groundwork

Interactive tools for learning how computers work, following the AQA A-level Computer Science course.

Tools

  • Assembly simulator

    Write programs in the AQA assembly language and run them one instruction at a time, watching the registers and memory change.

  • Logic gates

    Build circuits from logic gates and see their truth tables and Boolean expressions update as you go.

Groundwork follows the AQA A-level Computer Science specification (7517). It is not made or endorsed by AQA.
